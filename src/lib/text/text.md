# generic-text

Párrafo de cuerpo en IBM Plex Sans. Usalo para descripciones, ayudas y copy largo.

## Inputs

| Nombre | Tipo | Default |
| --- | --- | --- |
| `muted` | `boolean` | `false` |
| `size` | `sm \| md \| lg` | `md` |

## Uso

```html
<generic-text>El ranking se actualiza cada noche.</generic-text>
<generic-text [muted]="true" size="sm">Sin datos todavía.</generic-text>
```
