# generic-badge

Chip de estado. El texto entra por proyección.

## Inputs

| Nombre | Tipo | Default |
| --- | --- | --- |
| `tone` | `cyan \| magenta \| gold \| green \| red \| neutral` | `cyan` |
| `appearance` | `solid \| outline` | `outline` |
| `size` | `sm \| md` | `md` |

## Uso

```html
<generic-badge tone="green">Activo</generic-badge>
<generic-badge tone="red" appearance="solid">Vencido</generic-badge>
```
